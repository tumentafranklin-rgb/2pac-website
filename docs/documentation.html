Technical Documentation

AutoFix is a premium industrial-strength HTML5 template for automotive centers. It utilizing a zero-framework architecture for peak mobile performance and rugged mechanical aesthetics.

Project Structure

/car-repair-template
│
├── index.html              # Landing Page
├── css/styles.css          # Design System (Tokens)
├── js/main.js              # Interactivity
└── images/                 # Automotive Assets

Core Features

Hero Slider

High-precision imagery slider with custom fade transitions and nav dots.

Service Grid

Modular service blocks with slide-up animations and hover interactive states.

Stats Counter

JavaScript driven numeric counters to showcase shop success and experience icons.

Rugged UX

Consistent industrial design with metallic highlights and high-contrast typography.

Customization

Centralized Tokens

Update your shop's branding by editing the :root variables in styles.css.

:root {
    --color-primary: #ff4d4d;  /* Mechanic Red */
    --color-secondary: #1a1a1a; /* Industrial Grey */
}

Technical Details

  • HTML5 Semantic: Optimized for automotive local SEO.
  • Vanilla JS Slider: Pure implementation without heavy libraries.
  • Intersection Observer: Powers viewport-triggered animations for superior performance.

Browser Compatibility

Optimized for Google Chrome, Mozilla Firefox, Apple Safari, and Microsoft Edge.
